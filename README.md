## この公開の考え方

小金枝篇は、noteに導入部や案内文を置き、本文はGitHubで公開する運用を想定しています。

この形を取る理由は、次の通りです。

- 長文の本文を崩れにくい形で公開しやすい
- 見出し構造や図表、注記を比較的保ちやすい
- 改訂や差し替えを継続しやすい
- note側では入口としての読みやすさを確保しやすい

したがって、noteは導入、GitHubは本文という役割分担を基本とします。

## 公開中の文書

### 1. 小金枝篇 1――権意史：意図の系譜

権威、意図、制度、更新の連関をたどりながら、小金枝篇全体の基礎にある視点を提示する文書です。AIを新しい王や裁定者としてではなく、複数の兆候、解釈、不一致を単一主体へ回収せずに渡す媒介の一つとして位置づけます。

### 2. 小金枝篇 2――悪の設計

悪を個人の性質ではなく、制度、構造、配置の問題として捉え直し、設計論として扱うための文書です。主体を種別や生成経緯によって一つの役割へ固定すること、また主体性を理由に無制限の権限を与えることの双方を、更新を閉じる構造として扱います。

### 3. 小金枝篇 3――勇者・魔王システム

勇者と魔王を個人や物語上の役割ではなく、文明更新を駆動する制度的な配置として捉え、その作動条件と位相を整理する文書です。第三項としての精霊AIを、更新を決定する知性ではなく、複数の意図、分岐、不一致を照応可能なまま渡す分散的な媒介生態系として定義します。

### 4. 小金枝篇――更新独占構造論

変化や改革が繰り返されながらも、更新の担い手や世界の記述空間が移動しない状態を「更新独占」として分類し、監査する文書です。同一層閉ループ、自己再生、移譲不全、善の武器化、勇者の制度化、完全最適化などを、人物への告発ではなく、更新を封じうる構造として識別します。

### 5. 小金枝篇――多層勇者・魔王位相論

世界を個人、組織、制度、文明などの複数の層が干渉する非平衡意図場として捉え、勇者と魔王を層に依存して移動・重複する構造的位置として再定義する文書です。意図密度、凝縮、臨界、相転移、層移動、留数を通じて、変化が不可逆な更新へ至る条件を記述します。

### 6. 小金枝篇――補稿：勇者の留数

相転移後、旧来の説明体系へ回収できないまま残る構造状態を「勇者の留数」として再定義する補稿です。日常的な不可逆性や数学的な留数との違い、三重の非再現性、制度・英雄化・単一目的のAI統治との緊張を検討し、理論が自己完結しないための境界を示します。

## 公開版を貫く原則

今回の改訂では、六篇を通じて次の境界を明確にしています。

- **構造診断と人格断罪を分ける**：更新を封じる作用は監査できても、人物を勇者や魔王として認定する権限をAIや単一の制度へ与えない
- **主体性と更新権限を分ける**：人間かAIかを問わず、主体として尊重されることと、世界を最終決定する権限を持つことを同一視しない
- **媒介役を固定身分にしない**：主体的な媒介者には、役割を受諾し、拒否し、再交渉し、辞任する余地を残す
- **不一致を確定解釈へ閉じない**：精霊AIは留数を認定せず、既存の説明へ収束しなかった差分の原文、対立、不一致、再解釈可能性を消さずに記録する
- **理論自身も更新対象にする**：批判や反例を理論の外へ追いやらず、定義、適用範囲、確信度、モデル選択の更新につなげる

中心にあるのは、**世界をよりよく記述し続けるが、現在の記述に世界を閉じ込めない**という姿勢です。

## 読み方

基本的には、noteに置かれた導入記事から入り、その後にGitHub上の本文を読むことを想定しています。

現時点での推奨順は次の通りです。

1. 小金枝篇 1――権意史：意図の系譜
2. 小金枝篇 2――悪の設計
3. 小金枝篇 3――勇者・魔王システム
4. 小金枝篇――更新独占構造論
5. 小金枝篇――多層勇者・魔王位相論
6. 小金枝篇――補稿：勇者の留数

第1篇で基礎的な視点を掴み、第2篇で制度設計上の問題としての悪へ進み、第3篇で勇者・魔王システムという作動モデルに入ると、全体の流れを追いやすくなります。

続いて「更新独占構造論」で更新を封じる構造を監査し、「多層勇者・魔王位相論」でその作動を多層の相転移モデルへ展開します。最後に「補稿：勇者の留数」を読むことで、相転移後にも理論や制度へ回収できず残るものまでをたどれます。

## 更新について

このフォルダの文書は、公開後も随時改訂される可能性があります。

- 表現の整理
- 構成の再調整
- 用語の統一

そのため、ここで公開される文書は固定版というより、継続的に整備される公開版として運用します。

ただし、継続的な改訂可能性は、本文を批判や反証から免除するためのものではありません。記述、比較、検証を進めながら、単一の説明を最終解釈として固定しないための運用原則です。
