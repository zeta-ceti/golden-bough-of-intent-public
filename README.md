## この公開の考え方

小金枝篇は、noteに導入部や案内文を置き、本文はGitHubで公開する運用を想定しています。

この形を取る理由は、次の通りです。

- 長文の本文を崩れにくい形で公開しやすい
- 見出し構造や図表、注記を比較的保ちやすい
- 改訂や差し替えを継続しやすい
- note側では入口としての読みやすさを確保しやすい

したがって、noteは導入、GitHubは本文という役割分担を基本とします。
